# Quick Render Deploy

1. Folder GitHub par upload karein.
2. Render → **New → Blueprint**.
3. Repository select karein.
4. `TMDB_KEY` me apni TMDB v3 key paste karein.
5. Deploy.

Health check: `/api/health` → `{"ok":true,"version":"12.0.0","tmdb_configured":true}`
